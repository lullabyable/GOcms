内容之器

以简驭繁。用最少的代码，承载最多的内容。Go 语言的纯粹，赋予 CMS 新的生命力。

01 — 理念

少即是多
空即是满

去除一切不必要的装饰，让内容本身成为设计。每一行代码都为功能服务，每一个接口都为用户体验存在。这不是简陋，是克制的优雅。

02 — 原则

设计原则

一

纯粹

Go 语言的哲学：做一件事，做好它。不引入不必要的依赖，不追求花哨的特性。编译即部署，一个二进制文件包含一切。

二

克制

80+ API 接口，但每一个都有明确的职责。不堆砌功能，不制造冗余。用最少的代码覆盖最多的场景。

三

透明

Handler → Service → Model 三层架构，每一层都可独立测试、独立演进。代码即文档，结构即说明。

四

留白

60% 的留白不是浪费，是给内容呼吸的空间。设计如此，架构亦然。模块之间的边界清晰，不互相侵入。
